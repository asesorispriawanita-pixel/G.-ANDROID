# GPS Sensor Family
Aplikasi Android dengan mode ADMIN dan TARGET 1/2/3.

Fitur v1:
- Firebase Realtime Database
- GPS realtime target
- status izin Android
- daftar sensor perangkat
- shortcut Usage Access
- shortcut Notification Access
- status baterai
- riwayat GPS
- uji izin kamera/mikrofon secara transparan

Catatan privasi:
Kamera dan mikrofon tidak diaktifkan diam-diam. Aplikasi harus mengikuti izin Android dan tindakan pengguna.
Notification Listener hanya bekerja setelah pemilik perangkat mengaktifkannya di Pengaturan.
Usage Access juga harus diberikan secara manual.
Akses call log/WhatsApp database pribadi tidak dilakukan.
